# ADR 0005 — PWA (manifest + service worker) — deferred

**Status:** Deferred (planned)
**Date:** 2026-08-16

## Context

The app is already offline-capable (static files + IndexedDB) but not
installable. GitHub Pages supports service workers and manifests (plain
HTTPS static hosting).

## Decision

- Add PWA later as an incremental step, not now:
  - `manifest.json` (name, icons from `public/logo.svg`-derived assets,
    standalone display, theme color from the accent system).
  - Service worker: **cache-first for hashed `_next/static/*` assets**,
    **network-first for `index.html`/navigation** (so deploys propagate),
    offline fallback to the cached shell, `404.html` deep-link handling.
  - No COOP/COEP needed (plain SW).
- Revisit priority after the Phase 0 cleanup items and comments e2e
  verification.

## Consequences

- ✅ Installable + offline launch when implemented.
- ⚠️ Requires care: stale-shell updates are the classic failure mode;
  mitigated by network-first navigation + versioned SW.
